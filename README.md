# Sales Management System

## 📌 Project Overview
This is a Sales Management web application built using Python (Flask) and an SQLite database. It is designed to easily manage and track sales data, products, and customer transactions.

## 🚀 Features
* Add, view, and manage sales transactions seamlessly.
* Secure data storage using an SQLite database (`sales.db`).
* A user-friendly web interface powered by HTML, CSS, and JavaScript (`index.html`, `style.css`, `script.js`).
* Includes the complete project presentation (`Sales-Management-Ppt.pptx`).

## 🛠️ Technologies Used
* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
